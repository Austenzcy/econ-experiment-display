# 交流时点与信任博弈中的合作行为

16页、16:9的HTML研究汇报。全部图表和资源均在本地，可离线播放。

## 打开

克隆或下载仓库并解压，双击根目录的 `index.html`。不需要安装依赖或启动服务器，请保留 `assets/` 文件夹的相对位置。

- 右箭头、空格、Page Down：下一页。
- 左箭头、Page Up：上一页。
- Home / End：第一页 / 最后一页。
- F：进入或退出全屏。
- A：关闭或开启动画。
- 鼠标移至底部中间可显示控制按钮；悬停数据点或热力图单元可查看数值。
- 支持触摸左右滑动。建议使用电脑或横屏播放。

十轮折线约1.05秒绘出，热力图约0.99秒逐列显示；返回页面可重播。系统“减少动态效果”设置会默认关闭动画。无外部CDN或网络依赖。

## 文件

- `index.html`：幻灯片入口。
- `assets/slides.js`、`assets/style.css`：内容、原生SVG图表和样式。
- `assets/data.js`、`assets/statistics.json`：匿名绘图数据与统计量。
- `screenshots/index.html`：16页截图浏览页。
- `screenshots/slide-01.png`至`slide-16.png`：逐页1920×1080截图。
- `screenshots/contact-sheet.jpg`：截图总览。

## 数据口径

统计量根据2026年10月26日导出的实验资料重新核验。主分析为提前交流E组10对、中途交流M组9对，共190条搭档—轮次记录。两对工作人员补位配对从主分析中整对排除，全部21对仅用于敏感性比较。

返还比例为各对先计算 `e/(3x)` 与 `r/(3x)` 后再取均值；`x=0` 时比例无定义，比例散点共178条记录。散点显示的微小抖动不进入统计计算。相关性仅作描述，重复观察不能视为190个独立实验样本。

R6—R10平均转出为E组5.580点、M组5.377778点，差0.202222点；95% Welch参考区间为[−1.113607, 1.518052]。区间按搭档汇总计算。每种处理仅一间教室，不能据此作确定的因果推断。

热力图沿用原分析报告的连续蓝色色阶，按真实匿名配对编号排列：E01—E10，M02—M09、M11。原PPT中M组的重编号已统一。
